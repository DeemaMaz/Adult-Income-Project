Adult Income Prediction Project

Project Description & Objectives
The primary objective of this project is to apply data mining techniques—specifically classification and clustering—to a real-world dataset. The goal is to predict whether a person earns over $50,000 a year based on demographic and employment-related features (such as education, age, hours per week, and occupation).

Project Motivation
Predicting income levels helps in understanding socioeconomic factors and trends. Choosing the Adult dataset allows us to explore both classification performance (comparing decision trees and other models) and unsupervised patterns through clustering, referencing foundational machine learning research.
